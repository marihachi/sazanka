# UI

## アイコン

- アイコンは `src/assets/icons/` に SVG のアセットとして置く（ユーザーの指定）。コンポーネントの中にインラインで書かない。
- アイコンの SVG は CSS の `mask` として使い、形を切り抜いて文字色（`currentColor`）で塗っている。そのため、SVG の中で指定した色は表示に反映されない。塗る部分は不透明な色（`#000`）で描き、透明な部分が背景になる。色分けしたアイコンが必要になった場合は、この方式を見直す必要がある。

## ダイアログ

- ブラウザの `prompt` / `confirm` / `alert` は使わない。ユーザーは VS Code 内のブラウザで動かしていて、そこではこれらが何もせずに終わる（`prompt` は null、`confirm` は false を返す）。以前これが原因で「+ モジュール」が動かなかった。
  - 代わりに `src/Dialogs.tsx` の画面内 UI（`Dialog`、`InlineInput`）を使う。

## ドラッグ

- 部品のドラッグでは、キャンバス（svg）にポインターキャプチャを設定している。削除エリアなど、キャンバスの外まで動きを追うため。
  - キャプチャ中は click や dblclick がキャンバスに届き、部品には届かない。そのため、キャプチャは押した位置から少し動いてから設定する。押した時点で設定すると、ダブルクリック（ラベル編集、モジュールを開く）が動かなくなる。以前これで壊したことがある。

# UI

回路を描く領域は「シート」（コンポーネントは `Sheet`）と呼ぶ（プロジェクトの方針）。コメントやドキュメントでも「キャンバス」とは呼ばない。

どの操作に何を割り当てているかは[画面操作](interaction.md)にある。

## 画面の配置

- 操作は、効く範囲で置き場所を分けている（開発者の方針）。操作を足すときも、どちらに効くかで置き場所を決める。
  - プロジェクト全体に効く操作（新規作成、書き出し、読み込み、元に戻す、やり直し）は、ヘッダー（`Header.tsx`）。元に戻すの履歴はすべての回路で1本なので、全体の操作として扱う。
  - 回路（タブ）の切り替えと、モジュールの追加は、タブバー（`TabBar.tsx`）。追加はタブの末尾の「+」。追加できるのはモジュールだけで、メイン回路は 1 つだけ。
  - 部品の一覧はシートの左のパレット（`Palette.tsx`）。
  - 開いている回路に効く操作（シミュレーションの一時停止・1 tick 送り、モジュールの削除）は、タブの下のシートのツールバー（`SheetToolbar.tsx`）。選択中のタブと同じ色にして、そのタブの中の操作だと見せている。
  - シートの表示の拡大縮小は、シートの右下に重ねる（`ZoomControls.tsx`）。
  - 選んだ部品の項目（CLOCK の周期、INPUT / OUTPUT のラベルなど、部品ごとのプロパティ）は、シートの右側のプロパティ欄（`PropertyPanel.tsx`）で編集する（開発者の方針）。狭い画面（幅 720px 以下）では、部品を選んでいる間だけ出す。部品に項目を足すときは、ここに入力欄を足す。
  - 環境設定のウィンドウ（`Dialogs.tsx` の `PreferencesDialog`）を開くボタンは、ヘッダーの右端（このアプリについての隣）。環境設定は利用者ごとの値で、プロジェクトには含めない（型と選択肢は `components/preferences.ts`）。
- 取り消しにくい危険な操作のボタン（モジュールの削除など）は、`ToolButton` の `danger` で赤（`--danger`）にする。
- ボタンは `ToolButton.tsx` を使う。狭い画面（幅 720px 以下）では文字を隠してアイコンだけにし、文字はツールチップと読み上げ用のラベルに残す。

## アイコン

- アイコンは `src/assets/icons/` に SVG のアセットとして置く（プロジェクトの方針）。コンポーネントの中にインラインで書かない。
- アイコンの SVG は CSS の `mask` として使い、形を切り抜いて文字色（`currentColor`）で塗っている。そのため、SVG の中で指定した色は表示に反映されない。塗る部分は不透明な色（`#000`）で描き、透明な部分が背景になる。色分けしたアイコンが必要になった場合は、この方式を見直す必要がある。
- ロゴも同じ方式で、ロゴの色（`--brand`）で塗っている。ヘッダーは花だけ（`src/assets/logo-mark.svg`）、「このアプリについて」は文字付き（`src/assets/logo.svg`）（開発者の方針）。花の形を変えるときは、この2つとブラウザのタブのアイコンをそろえる。ロゴの色は固定で、環境設定のアクセントカラーでは変わらない（開発者の方針）。既定のアクセントカラー（青緑）はロゴと同じ色にしているので、ロゴの色を変えたら `preferences.ts` の既定値と選択肢、`style.css` の `--accent` も合わせる。ロゴの「sazanka」は、環境によって字形が変わらないよう、Inter SemiBold（SIL OFL）の字形をパスに変換して埋め込んでいる。文字やフォントを変えるときは、opentype.js などでパスを作り直す（大きさ 17px、ベースライン y=20、x=30 から、字間 0.5px）。文字の幅が変わったら、SVG の `viewBox` と、「このアプリについて」のロゴの大きさ（`Dialogs.module.css` の `.about-logo`）も合わせる。
- ブラウザのタブのアイコン（`public/favicon.svg`）は、ロゴの花だけを抜き出したもの。マスク方式ではなく、ロゴの色（`--brand` と同じ `lightseagreen`）を直接書いている。ロゴの花やロゴの色を変えたら、こちらも合わせて直す。
- アクセントカラーは、環境設定で利用者が変えられる（`preferences.ts` の `accent`）。`App.tsx` が `--accent` を差し替えるので、色は必ず `var(--accent)` か、それから作った色（`--accent-dim` など、`style.css`）で書く。アクセントカラーから作った色を直接書くと、色を変えたときに取り残される。

## ダイアログ

- ブラウザの `prompt` / `confirm` / `alert` は使わない。VS Code 内のブラウザなど、これらが何もせずに終わる環境がある（`prompt` は null、`confirm` は false を返す）。どの環境で開かれても動くようにするため。
  - 代わりに `src/components/Dialogs.tsx` の画面内のダイアログを使う。

## シートの表示（スクロールと拡大縮小）

表示を動かす操作の割り当ては[画面操作](interaction.md)にある。

- シートは横 300 マス・縦 200 マスの有限の大きさ（`layout.ts` の `SHEET_WIDTH` / `SHEET_HEIGHT`）。左上が回路の座標の原点で、部品はシートの中にだけ置ける（`clampPosition`）。座標は負にならず、保存データの形は変わらない。
  - 表示はシートの外まで自由に動かせる（開発者の方針）。シートの外は色（`--outside`）を変え、境目に線を引いている。シートの大きさを変えるときは、この表示（`Sheet.tsx` の `sheetStart` / `sheetEnd` を使う部分）も合わせて確かめる。
  - シートより外にある部品（大きさを決める前に作った回路など）も、そのまま表示・計算する。動かしたときに初めてシートの中へ戻る。
- 表示の位置と倍率（`components/view.ts` の `View`）は、回路の座標を描く `<g>` の transform と、方眼の patternTransform の両方に掛けている。ポインターの位置は `toWorld` で回路の座標に直してから使う。ラベルの入力欄のような HTML の要素は拡大縮小せず、位置だけ `toScreen` で合わせる。
- 表示は回路ごとに覚え、localStorage に保存する（[保存データ](persistence.md)）。元に戻す対象にはしない。
  - 表示を保存していない回路は、開いた時点の表示をすぐに保存して固定する（`App.tsx`）。固定しないと、部品を置くたびに表示が計算し直され、画面が勝手に動く。
- 表示を保存していない回路の開き方（`view.ts` の `overview`）:
  - 部品のない回路は、シートの中央を画面の真ん中に置いた等倍の表示で開く（開発者の方針）。
  - 部品のある回路は、回路全体が見える表示で開く。既存の回路はシートの左上の近くに部品があるので、中央を表示すると隠れてしまうため。
  - 「回路全体を表示」も同じ関数を使う。シートの外が映る場合は、シートの端を画面の端に合わせる。

## ステータスバーのヒント

- 分かりにくい操作や仕様に気付いたら、ステータスバーのヒントに適宜追加する（プロジェクトの方針）。機能を追加・変更したときも、ヒントが必要か考える。
- ヒントは短い文に分けて、時間で順に切り替えて表示する。操作の途中（配線中、ドラッグ中、編集中）は、そのとき必要な1文だけを出す。

# 画面操作

シートの上で、どの操作に何を割り当てているかと、その理由。画面の配置や見た目は [UI](ui.md)、時間を進める操作（一時停止・1 tick 送り）は [シミュレーション](simulation.md) にある。

操作を足すときは、次の割り当てとぶつからないかを確かめる。ぶつかるときは、どちらを優先するかを決めて[ステータスバーのヒント](ui.md)にも書く。

## 選択

- 部品はクリックで選ぶ。Shift を押しながらのクリックは、選択に足す・外す（押した部品は動かさない）。
- 何もないところからのドラッグは範囲選択。**全体が範囲に収まった部品だけ**を選ぶ（一部がかかっただけの部品は選ばない）。Shift を押しながら始めると、元の選択に足す。
- 選択中の部品を押してドラッグすると、選択中の部品をまとめて動かす。
- 配線は1本だけ選べる。部品と配線を同時には選べない（`Sheet.tsx` の `Selection`）。
- Ctrl+A で回路の部品をすべて選ぶ。Esc は、貼り付け・配線・選択をまとめて取り消す。

## 配線

- **出力ピン → 入力ピン** の順でクリックしてつなぐ。逆順（入力ピンから始める）には対応していない。
- 配線の途中で何もないところをクリックすると、そこに折れる点を置ける。曲げ方を利用者が決められるようにするため。
- 入力ピンに入る配線は1本だけ。つながっている入力ピンに別の配線をつなぐと、前の配線と置き換わる（[編集と元に戻す](editing.md)）。
- 何もつないでいない状態で入力ピンを押すと、そのピンにつながっている配線を外す。配線を選んでから消す手間を省くため。
- 配線の中央の縦線はドラッグで左右に動かせる。動かした位置は折れる点として保存する。

## 部品を置く・モジュールを追加する

- パレットの部品はクリックでもドラッグ＆ドロップでも置ける。クリックしたときは表示している範囲の真ん中あたりに置き、続けて置いたときに重ならないよう少しずつずらす（`App.tsx` の `addComponent`）。ドラッグ＆ドロップは落とした位置に置く。
- タブの末尾の「+」でモジュールを追加する。押すと名前を尋ねるダイアログが開き、確定して初めてモジュールが作られてそのタブが開く（`App.tsx` の `createModule`）。既定の名前は「モジュール<n>」で、空の名前と、すでにある回路と同じ名前は断る。

## 削除

- Delete か Backspace で、選んでいる部品または配線を消す。
- 部品は、パレットの下の削除エリアへドラッグしても消せる。移動してから削除エリアで離した場合も、移動と削除で1回の操作として元に戻せる。

## コピーと貼り付け

- Ctrl+C / Ctrl+X でコピー・切り取り、Ctrl+V で貼り付け。対象は選んでいる部品と、その部品どうしをつなぐ配線。
- 貼り付けは、押した瞬間には置かない。コピーした部品がポインターについてきて、クリックした位置で確定する。どこに増えたのかが分かるようにするため。
- 貼り付け先の回路を含むモジュールは貼り付けられない（循環するため）。理由をダイアログで知らせる。
- クリップボードはアプリの中だけで持つ（OS のクリップボードは使わない）。回路の受け渡しは書き出し・読み込みで行う（[保存データ](persistence.md)）。

## その他の割り当て

- INPUT は、動かさずにクリックすると ON/OFF が切り替わる。ドラッグしたときは切り替えない。
- モジュールの部品をダブルクリックすると、その中身のタブを開く。
- 部品の項目（CLOCK の周期、ラベルなど）は、シート上ではなくプロパティ欄で編集する（[UI](ui.md)）。
- 文字を入力している間（input / textarea にフォーカスがある間）と、ダイアログを開いている間は、ショートカットを効かせない（`useShortcuts`）。

## 表示を動かす

- ホイールで拡大縮小（トラックパッドのピンチも Ctrl 付きのホイールとして届く）、中ボタンか Space を押しながらのドラッグで移動、スマホでは2本指で移動と拡大縮小（開発者の方針）。何もないところのドラッグは、パソコンでもスマホでも範囲選択のまま。
- 表示の範囲や倍率そのものの決まりは [UI](ui.md) にある。

## ポインターの扱い（実装上の注意）

- シートには `touch-action: none` を付けている。付けないと、スマホで指を動かし始めた時点でブラウザがスクロールとして扱い、pointercancel が来てドラッグが止まる。シートの上の操作はすべて Pointer Events で受けているので、タッチ専用の処理は持っていない。
- 部品のドラッグでは、シート（svg）にポインターキャプチャを設定している。削除エリアなど、シートの外まで動きを追うため。
  - キャプチャ中は click や dblclick がシートに届き、部品には届かない。そのため、キャプチャは押した位置から少し動いてから設定する（`DRAG_THRESHOLD`）。押した時点で設定すると、ダブルクリック（モジュールを開く）が動かなくなる。
  - 何もないところから始める範囲選択は、クリックで何かをすることがないので、押した時点でキャプチャしている。
- ホイールは `addEventListener` で `passive: false` を付けて登録している。React の `onWheel` は passive になり、`preventDefault` が効かずにページごと拡大されてしまうため。
- 表示の移動と2本指の操作は `onPointerDownCapture` で子要素より先に受け取り、そこで止める。部品の上から始めても、部品のドラッグや配線が始まらないようにするため。
- 2本目の指が触れたら、1本目で始めていた部品のドラッグや範囲選択は打ち切る。2本指の操作の後は、指がすべて離れるまで1本目の操作を再開しない。
- 部品をまとめて動かすときの移動量は、どの部品もシートからはみ出さない範囲に縮める（`layout.ts` の `clampMove`）。全体の形を崩さないため、部品ごとには止めない。

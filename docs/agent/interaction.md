# 画面操作

シートとタブで、どう操作すると何が起きるかと、そう決めた理由。編集したデータと元に戻すの扱いは[編集と元に戻す](editing.md)、表示の範囲と倍率は[シートの表示](view.md)、ボタンの置き場所は [UI](ui.md) にある。

操作を足すときは、ここの割り当てとぶつからないかを確かめる。ぶつかるなら、どちらを優先するかを決め、ステータスバーのヒント（`hints/hints.ts`）にも書く。

## 選択

- 部品はクリックで選ぶ。Shift+クリックは選択に足す・外す（押した部品は動かさない）。
- 何もないところからのドラッグは範囲選択。本体の全体が範囲に収まった部品だけを選ぶ（ピンの先は含めない。`layout.ts` の `componentsInRect`）。Shift を押しながら始めると、元の選択に足す。
- 選択中の部品を押してドラッグすると、選択中の部品をまとめて動かす。
- 配線はクリックで 1 本だけ選べる。部品と配線を同時には選べない（`edit.ts` の `Selection`）。
- Ctrl+A で、開いている回路の部品をすべて選ぶ。
- Esc を押すと、貼り付け中・配線中・選択をまとめて取り消す。

## 配線

- 出力ピン → 入力ピンの順にクリックしてつなぐ。入力ピンから始めることはできない。
- 配線中に何もないところをクリックすると、そこに折れる点を置く（グリッドに合わせる）。曲げ方を利用者が決められるようにするため。自動で経路を探す方式は、配線が多いと計算が重く、経路が勝手に変わるので採らない。
- 配線中の仮の線（`Sheet.tsx` の `pendingPath`）は、クリックで確定したときと同じ形に描く。何もないところでは折れる点を置いたときの形（横→縦）、入力ピンの上ではそのピンへ入る形（縦→横）。形がずれると、クリックした後に線が違う位置へ動いて見える。`wireRoute` の曲がり方を変えるときは、ここも合わせる。
- 配線中でないときに入力ピンを押すと、そのピンの配線を外す。配線を選んでから消す手間を省くため。
- 中間で 1 回折れる配線は、中央の縦線をドラッグで左右に動かせる。

## 部品を置く・動かす・消す

- パレットの部品は、クリックでもドラッグ＆ドロップでも置ける。
  - クリックしたときは、表示している範囲の真ん中あたりに置く。続けて置いても重ならないよう、少しずつずらす（`App.tsx` の `addComponent`）。
  - ドラッグ＆ドロップは、落とした位置に置く。ブラウザのドラッグ＆ドロップ（`dataTransfer`、形は `palette/drag.ts`）を使っている。
- 部品の位置はグリッド（20）に合わせ、シートからはみ出さない位置に収める（[シートの表示](view.md)）。
- まとめて動かすときの移動量は、どの部品もはみ出さない範囲に縮める（`layout.ts` の `clampMove`）。全体の形を崩さないため、部品ごとには止めない。
- INPUT は、動かさずにクリックすると ON/OFF が切り替わる。ドラッグしたときは切り替えない。
- モジュールの部品をダブルクリックすると、その中身のタブを開く。
- 部品の項目（CLOCK の周期、ラベル）は、シートではなくプロパティ欄で編集する。使える値になったら、すぐに反映する。
- Delete か Backspace で、選んでいる部品か配線を消す。部品は、シートの右下の削除エリアへドラッグしても消せる。

## コピーと貼り付け

- Ctrl+C でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付け。対象は、選んでいる部品と、その部品どうしをつなぐ配線。
- 貼り付けは、押した瞬間には置かない。部品がポインターについてきて、クリックした位置で確定する。どこに増えたのかが分かるようにするため。(開発者からの指示)
  - ポインターがまだシートに来ていない（スマホなど）ときは、表示している範囲の真ん中に出す。
  - 押したまま大きく動かしてから離したときは、確定しない（指で画面をなぞっただけのときなど）。貼り付け中のまま残る。
- 貼り付け先の回路を含むモジュールは貼り付けられない（循環するため）。理由をダイアログで知らせる。
- クリップボードはアプリの中だけで持つ（OS のクリップボードは使わない）。回路の受け渡しは、書き出しと読み込みで行う（[保存データ](persistence.md)）。

## タブ

- タブをクリックすると、その回路を開く。開くのはクリック（Chakra の `Tabs` の選択）だけ。
- タブの末尾の「+」でモジュールを追加する。名前を入れるダイアログで確定して初めて、モジュールができてそのタブが開く。
- モジュールのタブは、ダブルクリックで名前を変えられる（Enter を押すか欄を離れると確定し、Esc で取り消す）。ドラッグで並べ替えもできる。メイン回路のタブは、どちらもできない。
- 押した位置から少し動かしたら（`DRAG_THRESHOLD`）ドラッグとして扱い、タブは開かない。ポインターキャプチャは動き始めてから設定する。押した時点で設定すると、ダブルクリックが効かなくなるため。
- モジュールのタブを並べ替えても、開いているタブは変えない。(開発者からの指示)

## 表示を動かす

- ホイールで拡大縮小する（トラックパッドのピンチも、Ctrl 付きのホイールとして届く）。
- 中ボタンでのドラッグか、Space を押しながらのドラッグで、表示を動かす。
- スマホでは、2 本指で移動と拡大縮小ができる。
- 何もないところからのドラッグは、パソコンでもスマホでも範囲選択になる（表示の移動にはしない）。

## キーボード

- キーボードの操作は `editing/useShortcuts.ts` にまとめている。Ctrl の代わりに Cmd も効く。
- 元に戻すは Ctrl+Z、やり直しは Ctrl+Shift+Z か Ctrl+Y。
- 文字を入力している間（input か textarea にフォーカスがある間）と、ダイアログを開いている間は、ショートカットを効かせない。Space による表示の移動も、文字の入力中は効かせない。

## ポインターの扱い（実装の注意）

- シートの上の操作は、すべて Pointer Events で受ける。タッチ専用の処理は持っていない。
- シートには `touch-action: none` を付けている。付けないと、スマホで指を動かし始めた時点でブラウザがスクロールとして扱い、`pointercancel` が来てドラッグが止まる。
- 部品のドラッグでは、シートの `svg` にポインターキャプチャを設定する。削除エリアなど、シートの外まで動きを追うため。
  - キャプチャ中は click や dblclick がシートに届き、部品には届かない。そのため、キャプチャは押した位置から少し動いてから（`DRAG_THRESHOLD`）設定する。押した時点で設定すると、ダブルクリック（モジュールを開く）が効かなくなる。
  - 何もないところから始める範囲選択は、クリックしても何も起きないので、押した時点でキャプチャする。
- ホイールは `addEventListener` に `passive: false` を付けて登録している。React の `onWheel` は passive になり、`preventDefault` が効かずにページごと拡大されてしまうため。
- 表示を動かす操作は `sheet/useViewGestures.ts` にまとめ、シートのポインターのイベントから呼ぶ。表示の移動と 2 本指の操作は `onPointerDownCapture` で子要素より先に受け、そこで止める。部品の上から始めても、部品のドラッグや配線が始まらないようにするため。
- 2 本目の指が触れたら、1 本目で始めていた部品のドラッグや範囲選択は打ち切る。2 本指の操作のあとは、指がすべて離れるまで 1 本目の操作を再開しない。
- 削除エリアとズームは、自分の上で起きた `pointerdown` をシートへ伝えない。その上から押しても、範囲選択が始まらないようにするため。

## 触ったら確かめること

タブバー（`TabBar.tsx`）を触ったら、ヘッドレスブラウザ（Skill の `browser-check`）で次を確かめる。Chakra の `Tabs` の選択と、自前のドラッグ・名前の変更が同じ要素に乗っているので、片方を直すともう片方が壊れやすい。

- 「+」でモジュールを追加すると、タブが増えてそれが開く。
- タブをクリックすると、その回路に切り替わる。
- モジュールのタブをダブルクリックすると名前を変えられ、Enter で確定する。
- モジュールのタブをドラッグすると並べ替えられ、ドラッグ中は点線の枠が出る。並べ替えても、開いているタブは変わらない。
- 並べ替えのあと、元に戻すが押せる。

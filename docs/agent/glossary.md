# 用語

このアプリで使う言葉と、コードの中での名前の対応。ドキュメント・UI の文言・コードコメントでは、ここの言い方にそろえる。

## 人の呼び分け

- 開発者: エージェントに指示する人。複数人いる想定（[AGENTS.md](../../AGENTS.md)）。
- 利用者: できあがったアプリを使う人。

## 回路のデータ

| 言葉               | コードでの名前            | 意味                                                                                           |
| ------------------ | ------------------------- | ---------------------------------------------------------------------------------------------- |
| プロジェクト       | `Project`                 | メイン回路とすべてのモジュールをまとめたもの。保存・書き出しの単位                             |
| 回路               | `Circuit` / `CircuitDef`  | 部品と配線の集まり。`CircuitDef` は、それに ID と名前が付いたもの（タブ1つ分）                 |
| メイン回路         | `MAIN_ID`（`'main'`）     | プロジェクトにいつも 1 つある、いちばん外側の回路。削除も追加もできない                        |
| モジュール         | 種類 `CUSTOM`             | 部品としてほかの回路に置ける回路。メイン回路以外の回路はすべてモジュール                       |
| 部品               | `Component`               | シートに置くもの（ゲート、フリップフロップ、INPUT、モジュールなど）                            |
| 部品の種類         | `ComponentKind`           | `AND`、`DFF`、`CUSTOM` など。内部用の `BUF` は利用者が置けない                                  |
| ピン               | `PinRef`                  | 部品の入出力の口。番号で指す。入力ピンは左、出力ピンは右                                       |
| 配線               | `Wire`                    | 出力ピンと入力ピンをつなぐ線                                                                   |
| 折れる点           | `Wire.points`             | 配線を曲げる位置。利用者が置いた順に通る                                                       |
| ラベル             | `Component.label`         | INPUT / OUTPUT に付ける名前。モジュールにしたときのピン名になる                                |

- 「回路」はメイン回路とモジュールをまとめた言い方。増やせるのはモジュールだけなので、増やす話は「モジュールの追加」と書く。
- モジュールの内部名が `CUSTOM` なのは、部品の種類の 1 つとして持っているため。ドキュメントと UI では「モジュール」と呼ぶ。

## 画面

| 言葉             | コードでの名前     | 意味                                                             |
| ---------------- | ------------------ | ---------------------------------------------------------------- |
| シート           | `Sheet`            | 回路を描く領域。「キャンバス」とは呼ばない                       |
| タブ / タブバー  | `TabBar`           | 回路を切り替える部分。タブ 1 つが回路 1 つ                       |
| パレット         | `Palette`          | シートの左にある、置ける部品の一覧                               |
| 削除エリア       | —                  | パレットの下にある、部品をドラッグして消す場所                   |
| シートのツールバー | `SheetToolbar`   | タブの下の、開いている回路に効く操作を並べた場所                 |
| プロパティ欄     | `PropertyPanel`    | シートの右にある、選んだ部品の項目を編集する場所                 |
| ステータスバー   | `StatusBar`        | 画面下の、ヒントと発振の警告を出す場所                           |
| 環境設定         | `Preferences`      | 利用者ごとの設定（tick の間隔、アクセントカラーなど）            |

## シミュレーション

| 言葉         | コードでの名前          | 意味                                                                         |
| ------------ | ----------------------- | ---------------------------------------------------------------------------- |
| tick         | —                       | シミュレーションの時間の単位。1 tick ごとに回路を 1 段進める                 |
| 遅延         | `delayOf`               | 部品の入力が変わってから出力に現れるまでの tick 数                           |
| 発振         | `SimResult.unstable`    | 入力を変えていないのに値が変わり続けている状態                               |
| 展開         | `flattenProject`        | モジュールの中身を最上位の回路に開いて、1 つの回路にすること                 |

## データの受け渡し

| 言葉         | 意味                                                                     |
| ------------ | ------------------------------------------------------------------------ |
| 保存データ   | localStorage に自動で保存するプロジェクト                                |
| 共有用 JSON  | 「書き出し」で作り、「読み込み」で取り込む JSON。他人に渡すためのもの     |

# シミュレーション

## 評価モデルの前提

- ゲート遅延は再現しない。全部品の評価を値が変わらなくなるまで繰り返す方式で、値が落ち着かなければ発振とみなす。そのため、ゲートを通したクロック（ゲーテッドクロックなど）は、実物と違う動きをすることがある。これは既知の制約として、ユーザーに説明済み。
- 計算するのは、いま開いているタブの回路だけ。サブ回路のタブを見ている間、メイン回路は止まっている（クロックも進まない）。これも説明済みの仕様。

## 壊してはいけない不変条件

- フリップフロップの状態や、ラッチのようなフィードバック回路の値は、前回の計算結果（`SimResult`）を部品 ID で引き継いで保っている。
  - 展開後の部品 ID の付け方（`外側の部品ID/内側の部品ID`）を変えると、状態が引き継がれずに消える。
  - 部品 ID を作り直すような処理を入れる場合も同じ。
- サブ回路のピンの順番は、定義の中の INPUT と OUTPUT を座標順（上から、同じ高さなら左から）に並べたもの。
  - そのため、サブ回路の中で INPUT や OUTPUT を動かすとピンの順番が入れ替わり、外側の配線が別のピンにつながってしまう。
  - ピン番号の決め方を変えるときは、既存の配線への影響を考えること。

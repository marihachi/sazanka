# アイコンとロゴ

画面に出す絵と色の決まり。画面の配置は[UI](ui.md)にある。

- アイコンは `src/assets/icons/` に SVG のアセットとして置く（プロジェクトの方針）。コンポーネントの中にインラインで書かない。
- アイコンの SVG は CSS の `mask` として使い、形を切り抜いて文字色（`currentColor`）で塗っている。そのため、SVG の中で指定した色は表示に反映されない。塗る部分は不透明な色（`#000`）で描き、透明な部分が背景になる。色分けしたアイコンが必要になった場合は、この方式を見直す必要がある。
- ロゴも同じ方式で、ロゴの色（`--brand`）で塗っている。ヘッダーは花だけ（`src/assets/logo-mark.svg`）、「このアプリについて」は文字付き（`src/assets/logo.svg`）（開発者の方針）。花の形を変えるときは、この2つとブラウザのタブのアイコンをそろえる。ロゴの色は固定で、環境設定のアクセントカラーでは変わらない（開発者の方針）。既定のアクセントカラー（青緑）はロゴと同じ色にしているので、ロゴの色を変えたら `preferences.ts` の既定値と選択肢、`style.css` の `--accent` も合わせる。ロゴの「sazanka」は、環境によって字形が変わらないよう、Inter SemiBold（SIL OFL）の字形をパスに変換して埋め込んでいる。文字やフォントを変えるときは、opentype.js などでパスを作り直す（大きさ 17px、ベースライン y=20、x=30 から、字間 0.5px）。文字の幅が変わったら、SVG の `viewBox` と、「このアプリについて」のロゴの大きさ（`Dialogs.tsx` の `AboutDialog` の `MaskIcon` の `w` と `h`）も合わせる。
- ブラウザのタブのアイコン（`public/favicon.svg`）は、ロゴの花だけを抜き出したもの。マスク方式ではなく、ロゴの色（`--brand` と同じ `lightseagreen`）を直接書いている。ロゴの花やロゴの色を変えたら、こちらも合わせて直す。
- アクセントカラーは、環境設定で利用者が変えられる（`preferences.ts` の `accent`）。`App.tsx` が `--accent` を差し替え、テーマ（`theme.ts`）の `accent` のパレットはそれから作っている。色は必ず Chakra の `colorPalette="accent"`（ページ全体の既定）か `accent.*` のトークンで書く。アクセントカラーから作った色を直接書くと、色を変えたときに取り残される。

## 触ったら確かめること

テーマ（`theme.ts`）や色の変数（`style.css`）を触ったら、ヘッドレスブラウザで次を確かめる。

- 環境設定でアクセントカラーを選び直すと、テーマの色も変わる。`getComputedStyle(document.documentElement)` で `--chakra-colors-accent-solid` を読み、選んだ色になっていればよい。
- シートの配線や部品の色（`--chakra-colors-sheet-*`）が、変える前と同じに出る。

# ライセンス

公開しているアプリ（GitHub Pages）は、同梱しているライブラリの複製を配布していることになる。ライブラリや素材のライセンスが求める表示を、配布物に必ず含めること（プロジェクトの方針）。

## 同梱しているライブラリ

- MIT などのライセンスは、配布物にライセンス文（著作権表示と許諾表示）を含めることを条件にしている。ビルドで JS を圧縮すると、ライブラリの中のライセンスのコメントは消えるので、それだけでは条件を満たさない。
- そのため、「このアプリについて」の画面に、同梱しているライブラリのライセンス文を表示している。
  - 一覧は手で書かず、ビルド時に集めている（`vite.config.ts` の `collectLicenses`）。`package.json` の `dependencies` と、そこから辿れるパッケージが対象。画面へは `import licenses from 'virtual:licenses'` で渡す。
  - ライセンス文のファイルが見つからないパッケージがあると、ビルドを止める。表示から黙って漏れないようにするため。止まったら、そのパッケージのライセンスを確かめ、表示の仕方を開発者に相談する。
  - `devDependencies`（Vite、TypeScript など）は配布物に入らないので対象外。ビルドや実行時に読み込むものを `devDependencies` に入れないこと。
- 依存ライブラリを足すときは、ライセンスが MIT と両立するか（GPL などで、このアプリのライセンスに影響しないか）と、ライセンス文の表示以外の条件がないかを確かめる。迷ったら開発者に相談する。

## 素材

- ロゴの文字は Inter SemiBold（SIL OFL）の字形をパスにして使っている（[UI](ui.md)）。フォントのファイル自体は配布していないので、ライセンスの表示は必須ではないと考えている（開発者の判断）。今は念のため、README と「このアプリについて」にフォント名とライセンスを書いている。
- アイコン（`src/assets/icons/`）は、このプロジェクトで描いたもの。外から素材を持ってくるときは、ライセンスを確かめ、必要な表示を「このアプリについて」に足す。

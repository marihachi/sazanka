# 保存データ

- 回路は localStorage に自動で保存している。ユーザーの手元の保存データを壊さないよう、形式を変えるときは古い形式を読み込めるようにしておくこと。
  - ただし未リリースの間は、ユーザーの判断で移行処理を省くことがある（例：モジュールの種類名を `'SUB'` から `'CUSTOM'` に変えたとき）。リリース後は必ず移行処理を用意する。
  - 現在のキーは `sazanka.project`。以前のキー `sazanka.circuit`（回路1つだけの形式）も、メイン回路として読み込めるようにしている。
- モジュールのピンが減って、存在しないピンを指すようになった配線も、削除せずにデータとして残している（表示と計算からは除いているだけ）。
  - ピンが元に戻れば配線も復活する、という前提。勝手に削除する処理を入れないこと。

# 回路ファイルの形式 version 1

sazanka の回路ファイル（選んだ回路を書き出したファイル）の形式（version 1）の仕様。中の回路は、[回路の形式](../circuit/v1.md)で書く。

version 1 は公開した（2026-10-24）。今ある項目や値は変えない。省略できる項目を足すのはよい（版は上げない。[保存データ](../../../agent/docs/persistence.md)の「形式を変えるとき」）。

- 回路をほかのプロジェクトへ持ち込んで再利用するためのファイル（UTF-8 の JSON）。回路が 1 つでも複数でも、いつもこの形にする。
- 版は、[プロジェクトの形式](../project/v1.md)と回路の形式とは別に数える。

## 回路ファイル

```json
{
  "format": "sazanka-circuits",
  "version": 1,
  "circuits": [
    { "format": "sazanka-circuit", "version": 1, "id": "7b3e…", "name": "全加算器", ... },
    { "format": "sazanka-circuit", "version": 1, "id": "c91a…", "name": "半加算器", ... }
  ]
}
```

| 項目       | 型     | 必須 | 内容                                                                     |
| ---------- | ------ | ---- | ------------------------------------------------------------------------ |
| `format`   | 文字列 | ○    | 回路ファイルであることの目印。常に `"sazanka-circuits"`                  |
| `version`  | 数値   | ○    | 形式の版。`1`                                                            |
| `circuits` | 配列   | ○    | [回路の形式](../circuit/v1.md)のデータ（版を含む）の並び。空でもよい   |

- 中の回路のデータは、プロジェクトの中の回路のデータと、まったく同じ形。
- メイン回路（`id` が `"main"`）は入れない。メイン回路の `id` はどのプロジェクトでも同じなので、持ち込むと見分けられないため。
- 回路の `id` は、ファイルの中で重ならない。名前は重なってもよい（持ち込むときに名前を変える）。
- フォルダは持たない。置くフォルダは持ち込み先のプロジェクトが決める（持ち込むときに選ぶ）。
- 回路が置いている回路（依存する回路）が、ファイルに入っているとは限らない（書き出すときに、含めるかを選べる）。モジュールの部品は、指す回路の名前と大きさの写し（`circuitName`、`circuitSize`）を持つので、持ち込み先に指す回路がなければ、見つからないモジュールとして元の大きさで開ける。
- 並びは、書き出したプロジェクトでの並びの順。持ち込むときに足す回路は、この順にプロジェクトの末尾へ並ぶ。

## ファイルの見分け方

データの種類は `format` で見分ける（[プロジェクトの形式](../project/v1.md)の「ファイルの見分け方」）。回路ファイルを読み込むときに、ほかの種類を選んでいたら、壊れたデータとは分けて知らせる。

- `"sazanka-project"` か一体の形式（`format` がなく、いちばん外に `version` と `project` を持つ）: プロジェクトファイル。プロジェクトとして開くように知らせる。
- `"sazanka-circuit"`: 回路の形式だけのデータ。回路ファイルとしては読めない（回路を 1 つだけ持ち込みたいときも、回路ファイルにする）。

## 読み込むときの検証

次を確かめる。1 つでも満たさなければ、読み込まずに断る。

- `format` が `"sazanka-circuits"` であること。
- `version` が数値で、今の版以下であること（新しい版のファイルは断る）。中の回路の `version` も、回路の形式の今の版以下であること。
- `circuits` が配列で、どの回路も[回路の形式の検証](../circuit/v1.md)を通ること（プロジェクトの中の回路と同じ確かめ方）。
- メイン回路がないこと。
- 回路の `id` が重ならないこと。

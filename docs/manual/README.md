# sazanka 操作マニュアル

sazanka は、ブラウザで動く論理回路シミュレータ。部品を置いて配線すると、その場で動く。

## 画面

| 場所               | 位置         | できること                                                                 |
| ------------------ | ------------ | -------------------------------------------------------------------------- |
| ヘッダー           | 最上部       | 元に戻す、やり直し、環境設定                                               |
| タブ               | ヘッダーの下 | 開いている回路の切り替え、閉じる（「×」）、並べ替え（ドラッグ）            |
| ツールバー         | タブの下     | モードの切り替え、回転、シミュレーションの操作、回路設定                   |
| アクティビティバー       | 左端         | 左のパネルに出すもの（プロジェクト、部品）の切り替え                       |
| プロジェクトパネル | 左           | プロジェクトの中の回路の一覧（フォルダの木）。ダブルクリックで開く         |
| パレット           | 左           | 置ける部品の一覧                                                           |
| シート             | 中央         | 回路を描く場所                                                             |
| プロパティ欄       | 右           | 選んだ部品の項目の編集                                                     |
| 削除エリア・ズーム | シートの右下 | 部品の削除、拡大縮小                                                       |
| 問題パネル         | シートの下   | 回路の問題（エラーと警告）の一覧                                           |
| ステータスバー     | 最下部       | 操作のヒント。右端の「問題」で問題パネルを開閉する                         |

狭い画面では、ボタンはアイコンだけになり、プロパティ欄は部品を選んでいる間だけ出る。

## 部品を置く

- パレットの部品をクリックすると、表示している範囲の真ん中に置く。
- シートへドラッグすると、落とした位置に置く。

### 部品の一覧

| グループ         | 部品                                      | 説明                                                  |
| ---------------- | ----------------------------------------- | ----------------------------------------------------- |
| 入出力           | INPUT                                     | スイッチ。クリックで ON/OFF                           |
|                  | OUTPUT                                    | ランプ。入力が ON で点灯                              |
| 信号源           | HIGH                                      | 常に ON                                               |
|                  | CLOCK                                     | 一定の周期で ON/OFF を繰り返す                        |
| 論理ゲート       | AND、OR、NOT、NAND、NOR、XOR、XNOR       | 基本の論理ゲート                                      |
| ラッチ           | RS Latch、RS-EN Latch、D Latch            | 入力にすぐ反応して値を保持する                        |
| フリップフロップ | D-FF、T-FF、JK-FF                         | CLK が OFF から ON になった瞬間だけ動く               |
| デバイス         | 7セグ                                     | 7 セグメントディスプレイ。ON の入力のセグメントが光る |
| モジュール       | 作ったモジュール                          | 下の「モジュール」                                    |

部品の詳しい動きは、パレットの部品にポインターを載せると出る。

## モード

ツールバーのボタンかキーで切り替える。

| モード     | キー | クリックの働き               |
| ---------- | ---- | ---------------------------- |
| 選択モード | `V`  | 部品や配線を選ぶ・動かす     |
| 配線モード | `W`  | 配線の点を置く               |
| 分割モード | `S`  | 配線をその点で 2 本に分ける  |

配線モードと分割モードは、`Esc` で選択モードに戻る。

## 選ぶ・動かす・消す（選択モード）

- クリックで選ぶ。`Shift`+クリックで選択に足す・外す。
- 何もないところからドラッグすると範囲選択。`Ctrl+A` ですべて選ぶ。
- 選んだものをドラッグすると、まとめて動く。
- `Delete` か、右下の削除エリアへのドラッグで消す。
- INPUT は、クリックで ON/OFF が切り替わる。

部品を動かしても、配線はついてこない。つながりが切れたら、配線も動かすか引き直す。

### 回す

- `R` で、選んだ部品と配線をまとめて時計回りに 90 度回す。`Shift+R` で反時計回り。ツールバーの「回転」でも時計回りに回せる。
- 部品と、それにつながる配線を一緒に選んで回すと、つながったまま回る。部品だけを回すと、配線はついてこない。
- 文字も部品と一緒に回る。
- 回すとシートからはみ出すときは回らず、ステータスバーに「はみ出すため回転できません」と出る。

## 配線（配線モード）

1. どこかをクリックして配線を始める（ほかの配線の途中から始めると分岐する）。
2. クリックするたびに、縦か横に伸ばして折れる点を置く。
3. ピンの先か、ほかの配線の上をクリックすると、つないで終わる。最後の点をもう一度クリックすると、その場で終わる。

`Esc` で描いている配線を取り消す。

- 配線の端がピンの先か、ほかの配線の上にあるとつながる。分岐した所には丸い印が出る。
- 配線の途中どうしが交わるだけでは、つながらない。

### 配線の調整

- 長さを変える: 選択モードで配線を 1 本だけ選び、両端の四角をドラッグする。
- 2 本に分ける: 分割モードで、配線の途中か折れる点をクリックする。

## コピーと貼り付け

- `Ctrl+C` でコピー、`Ctrl+X` で切り取り。
- `Ctrl+V` のあと、クリックした位置に貼り付ける。貼り付ける前に `R` で回せる。`Esc` で取り消す。

## 元に戻す

- `Ctrl+Z` で元に戻す。`Ctrl+Shift+Z` か `Ctrl+Y` でやり直し。
- INPUT の ON/OFF は元に戻す対象にならない。

Mac では `Ctrl` の代わりに `Cmd` も使える。

## 表示の移動と拡大縮小

| 操作     | パソコン                                          | スマホ          |
| -------- | ------------------------------------------------- | --------------- |
| 拡大縮小 | ホイール、トラックパッドのピンチ、右下のボタン    | 2 本指のピンチ  |
| 移動     | 中ボタンでドラッグ、`Space` を押しながらドラッグ | 2 本指のドラッグ |

右下の倍率を押すと等倍に戻り、□ のボタンで回路全体を表示する。

## シミュレーション

- 回路は置いたそばから動く。時間は tick の単位で進む。
- 部品には遅延があり、信号は 1 tick ずつ伝わる。
- ツールバーの「一時停止」で止め、「1 tick 進める」「1 tick 戻す」で 1 tick ずつ確かめられる（戻せるのは直前の 300 tick まで）。
- 進む速さ（1 秒に進める tick 数）は、環境設定で変える。回路が大きいと、指定より遅く進むことがある。

### 部品の項目

部品を 1 つ選ぶと、プロパティ欄で項目を編集できる。

- CLOCK: 周期（ON と OFF を一往復する tick 数）。
- INPUT / OUTPUT: ポート名。回路をモジュールとして置くと、ピンの名前になる。

### 問題

ステータスバーの右端の「問題」に、開いている回路のエラー（赤）と警告（オレンジ）の数が出る。押すと問題パネルが開き、一覧が出る。もう一度「問題」を押すか、パネルの右上の × で閉じる。行を押すと、元になっている部品や配線が選ばれ、画面の外にあればそこへ表示が動く。パネルの上の端をドラッグすると、高さを変えられる。ダブルクリックすると、元の高さに戻る。

| 問題                                       | 原因と直し方                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------- |
| 発振しています                             | 出力が自分の入力に戻るループで、値が決まらない。ループを見直す                      |
| 出力がぶつかっています                     | 1 つのつながりに出力ピンが 2 つ以上ある（赤い配線）。どちらかを外す               |
| ピンに出ていない INPUT / OUTPUT があります | 回路の中のポートがピンに割り当てられていない。「回路設定」で割り当てる |
| シートの外に部品か配線があります           | シートの外に部品か配線がある。動かすと、シートの中へ戻る                            |
| 見つからない回路                           | 置いたモジュールの回路がプロジェクトにない（「見つからない」と書いた箱で出る）。その回路を読み込み直す。見つからないモジュールは何も出力しない |

## 回路設定

ツールバーの「回路設定」で、開いている回路の設定を変える。メイン回路にもモジュールにも使える。設定は「全般」と「モジュール」のタブに分かれている。「適用」で、両方のタブの変更がまとめて 1 回の変更になる（元に戻す 1 回で戻る）。使えない値があるタブには、赤い丸が付く。

「全般」のタブ:

- 名前: 回路の名前。メイン回路にはない。ほかの回路と同じ名前にはできない。
- 作者名: 回路を作った人の名前。入れなくてもよい。書き出したファイルに入る。
- シートの大きさ（幅と高さ、マス）: 1 辺は 20〜1000 マス。最初は 300 × 200 マス。左上は動かず、右と下で広がったり縮んだりする。部品や配線が収まらない大きさにはできない（収まる大きさがエラーで出る）。

「モジュール」のタブ（モジュールとして置いたときの設定。右のプレビューで、置いたときの見た目を確かめながら変えられる）:

- パッケージ: ロジック（入力は左、出力は右）、DIP（左右にピン）、QFP（4 辺にピン）とピン数。
- ポートの名前: 各 INPUT / OUTPUT の名前。
- ピンの割り当て（DIP / QFP）: ピン番号ごとに、つなぐポートか NC（未接続）を選ぶ。

ロジックでは、ピンの順は中の INPUT / OUTPUT のポート番号の順で決まる（入力 1 がいちばん上）。INPUT / OUTPUT を動かしても、ピンの順は変わらない。ピンの順を変えるには、INPUT / OUTPUT を並べたい順に上下に動かしてから、ポートの一覧の「上から順に番号を振り直す」を押す（中の位置の順に番号を振り直す）。DIP / QFP に変えると、ポート番号の順にピン番号を割り当てる。

パッケージやピンの割り当てを変えると、置いた先の配線が外れたり別のピンにつながったりすることがある。適用したあとに確かめる。メイン回路はほかの回路に置けないので、パッケージを変えても配線には響かない。

## モジュール

回路を、1 つの部品（モジュール）としてほかの回路に置ける。

1. プロジェクトパネルの「⋯」の「新しい回路…」で、名前を付けて回路を追加する。
2. その回路のタブで回路を作る。中の INPUT が入力ピン、OUTPUT が出力ピンになる。
3. ほかの回路のパレットの「モジュール」グループから置く。

- 置いたモジュールをダブルクリックすると、その中身のタブが開く。
- 回路の名前は、プロジェクトパネルの行のメニュー（右クリック、長押し、行の「⋯」）の「名前を変える」か、行を選んで F2 で変える（「回路設定」の「全般」でも変えられる）。
- 行のメニューの「別のモジュールに差し替える…」で、その回路を置いている部品を、すべて別の回路に切り替えられる。ピンの数や並びが違うと、配線が外れたり別のピンにつながったりする。差し替えたあと、元の回路を削除することもできる。
- 行のメニューの「プロジェクトから削除…」で消す。モジュールとしてほかの回路に置いている回路も消せる。置いていた部品は「見つからない」の箱（見つからないモジュール）で残り、何も出力しない。元に戻すで戻せる。
- ほかの回路のタブを開いている間は、メイン回路のシミュレーションは止まる。

## フォルダ

プロジェクトパネルで、回路をフォルダに分けて整理できる。

- 「⋯」の「新しいフォルダ…」か、フォルダの行のメニューの「新しいフォルダ…」で作る。回路を追加するダイアログの「フォルダを作る」でも作れる。
- 行をドラッグすると、並べ替えたり、フォルダの行の上に落としてその中へ移したりできる。フォルダの外へ出すときは、フォルダの行の上下の端か、一覧のいちばん下の何もない所に落とす。
- 同じフォルダの中では、回路の名前は重ならない。移した先に同じ名前があれば、「 (2)」などが付く。
- フォルダの名前を変えると、中のものもまとめて移る。フォルダは、中が空のときだけ削除できる。

## 保存と共有

- プロジェクト（メイン回路とほかのすべての回路）は、ブラウザに自動で保存される。
- プロジェクトパネルの「⋯」の「名前を付けて保存…」で、プロジェクトをファイル（プロジェクトファイル）に保存する。Chrome や Edge では、保存場所とファイル名を選べる。Firefox や Safari では、ダウンロードとして保存される。
- 「開く…」で、保存したファイルを選ぶと、そのプロジェクトに置き換わる。開いたあとは、それより前の操作を元に戻せない。
- 「新規作成…」で、空のプロジェクトにする。新規作成は元に戻せない。
- 開いたあとと新規作成のあとは、タブがすべて閉じ、プロジェクトパネルが出る。

## 環境設定

ヘッダーの右端から開く。

- シミュレーションの速さ（tick/秒、1〜100000）
- 方眼の表示
- 配線の角を丸める
- アクセントカラー
- 言語（自動 / 日本語 / English）

# sazanka 操作マニュアル

sazanka は、ブラウザで動く論理回路シミュレータ。部品を置いて配線すると、その場で動く。

## 画面

| 場所               | 位置         | できること                                                       |
| ------------------ | ------------ | ---------------------------------------------------------------- |
| ヘッダー           | 最上部       | 新規作成、読み込み、書き出し、元に戻す、やり直し、環境設定       |
| タブ               | ヘッダーの下 | 回路の切り替え、モジュールの追加（「+」）                        |
| ツールバー         | タブの下     | モードの切り替え、シミュレーションの操作、シート設定、モジュール設定 |
| パレット           | 左           | 置ける部品の一覧                                                 |
| シート             | 中央         | 回路を描く場所                                                   |
| プロパティ欄       | 右           | 選んだ部品の項目の編集                                           |
| 削除エリア・ズーム | シートの右下 | 部品の削除、拡大縮小                                             |
| ステータスバー     | 最下部       | 操作のヒントと警告                                               |

狭い画面では、ボタンはアイコンだけになり、プロパティ欄は部品を選んでいる間だけ出る。

## 部品を置く

- パレットの部品をクリックすると、表示している範囲の真ん中に置く。
- シートへドラッグすると、落とした位置に置く。

### 部品の一覧

| グループ         | 部品                                      | 説明                                                  |
| ---------------- | ----------------------------------------- | ----------------------------------------------------- |
| 入出力           | INPUT                                     | スイッチ。クリックで ON/OFF                           |
|                  | OUTPUT                                    | ランプ。入力が ON で点灯                              |
| 信号源           | HIGH                                      | 常に ON                                               |
|                  | CLOCK                                     | 一定の周期で ON/OFF を繰り返す                        |
| 論理ゲート       | AND、OR、NOT、NAND、NOR、XOR、XNOR       | 基本の論理ゲート                                      |
| ラッチ           | RS Latch、RS-EN Latch、D Latch            | 入力にすぐ反応して値を保持する                        |
| フリップフロップ | D-FF、T-FF、JK-FF                         | CLK が OFF から ON になった瞬間だけ動く               |
| デバイス         | 7セグ                                     | 7 セグメントディスプレイ。ON の入力のセグメントが光る |
| モジュール       | 作ったモジュール                          | 下の「モジュール」                                    |

部品の詳しい動きは、パレットの部品にポインターを載せると出る。

## モード

ツールバーのボタンかキーで切り替える。

| モード     | キー | クリックの働き               |
| ---------- | ---- | ---------------------------- |
| 選択モード | `V`  | 部品や配線を選ぶ・動かす     |
| 配線モード | `W`  | 配線の点を置く               |
| 分割モード | `S`  | 配線をその点で 2 本に分ける  |

配線モードと分割モードは、`Esc` で選択モードに戻る。

## 選ぶ・動かす・消す（選択モード）

- クリックで選ぶ。`Shift`+クリックで選択に足す・外す。
- 何もないところからドラッグすると範囲選択。`Ctrl+A` ですべて選ぶ。
- 選んだものをドラッグすると、まとめて動く。
- `Delete` か、右下の削除エリアへのドラッグで消す。
- INPUT は、クリックで ON/OFF が切り替わる。

部品を動かしても、配線はついてこない。つながりが切れたら、配線も動かすか引き直す。

## 配線（配線モード）

1. どこかをクリックして配線を始める（ほかの配線の途中から始めると分岐する）。
2. クリックするたびに、縦か横に伸ばして折れる点を置く。
3. ピンの先か、ほかの配線の上をクリックすると、つないで終わる。最後の点をもう一度クリックすると、その場で終わる。

`Esc` で描いている配線を取り消す。

- 配線の端がピンの先か、ほかの配線の上にあるとつながる。分岐した所には丸い印が出る。
- 配線の途中どうしが交わるだけでは、つながらない。

### 配線の調整

- 長さを変える: 選択モードで配線を 1 本だけ選び、両端の四角をドラッグする。
- 2 本に分ける: 分割モードで、配線の途中か折れる点をクリックする。

## コピーと貼り付け

- `Ctrl+C` でコピー、`Ctrl+X` で切り取り。
- `Ctrl+V` のあと、クリックした位置に貼り付ける。`Esc` で取り消す。

## 元に戻す

- `Ctrl+Z` で元に戻す。`Ctrl+Shift+Z` か `Ctrl+Y` でやり直し。
- INPUT の ON/OFF は元に戻す対象にならない。

Mac では `Ctrl` の代わりに `Cmd` も使える。

## 表示の移動と拡大縮小

| 操作     | パソコン                                          | スマホ          |
| -------- | ------------------------------------------------- | --------------- |
| 拡大縮小 | ホイール、トラックパッドのピンチ、右下のボタン    | 2 本指のピンチ  |
| 移動     | 中ボタンでドラッグ、`Space` を押しながらドラッグ | 2 本指のドラッグ |

右下の倍率を押すと等倍に戻り、□ のボタンで回路全体を表示する。

## シミュレーション

- 回路は置いたそばから動く。時間は tick の単位で進む。
- 部品には遅延があり、信号は 1 tick ずつ伝わる。
- ツールバーの「一時停止」で止め、「1 tick 進める」「1 tick 戻す」で 1 tick ずつ確かめられる（戻せるのは直前の 300 tick まで）。
- 進む速さ（1 秒に進める tick 数）は、環境設定で変える。回路が大きいと、指定より遅く進むことがある。

### 部品の項目

部品を 1 つ選ぶと、プロパティ欄で項目を編集できる。

- CLOCK: 周期（ON と OFF を一往復する tick 数）。
- INPUT / OUTPUT: ラベル。モジュールの中では、ポート名（ピンの名前）になる。

### 警告

ステータスバーの右端に出る。

| 警告                                       | 原因と直し方                                                                        |
| ------------------------------------------ | ----------------------------------------------------------------------------------- |
| 発振しています                             | 出力が自分の入力に戻るループで、値が決まらない。ループを見直す                      |
| 出力がぶつかっています                     | 1 つのつながりに出力ピンが 2 つ以上ある（赤い配線）。どちらかを外す               |
| ピンに出ていない INPUT / OUTPUT があります | モジュールの中のポートがピンに割り当てられていない。「モジュール設定」で割り当てる |
| シートの外に部品か配線があります           | シートの外に部品か配線がある。動かすと、シートの中へ戻る                            |

## シート設定

ツールバーの「シート設定」で、開いている回路のシートの大きさ（幅と高さ、マス）を変える。メイン回路にもモジュールにも使える。

- 1 辺は 20〜1000 マス。最初は 300 × 200 マス。
- 左上は動かず、右と下で広がったり縮んだりする。
- 部品や配線が収まらない大きさにはできない。収まる大きさがエラーで出る。

## モジュール

回路をまとめて、1 つの部品として使える。

1. タブの「+」で名前を付けてモジュールを追加する。
2. モジュールのタブで回路を作る。中の INPUT が入力ピン、OUTPUT が出力ピンになる。
3. ほかの回路のパレットの「モジュール」グループから置く。

- 置いたモジュールをダブルクリックすると、その中身のタブが開く。
- モジュールのタブは、ダブルクリックで名前を変え、ドラッグで並べ替える。
- ツールバーの「モジュールを削除」で消す。ほかの回路で使っているモジュールは消せない。
- モジュールのタブを開いている間は、メイン回路のシミュレーションは止まる。

### モジュール設定

モジュールのタブで、ツールバーの「モジュール設定」から開く。右のプレビューで見た目を確かめながら変えられる。

- パッケージ: ロジック（入力は左、出力は右）、DIP（左右にピン）、QFP（4 辺にピン）とピン数。
- ポート: 各 INPUT / OUTPUT の名前。
- ピンの割り当て（DIP / QFP）: ピン番号ごとに、つなぐポートか NC（未接続）を選ぶ。

ロジックでは、ピンの順は中の INPUT / OUTPUT の上下の並びで決まる。並びを変えると、外側の配線が別のピンにつながるので注意する。

パッケージやピンの割り当てを変えると、置いた先の配線が外れたり別のピンにつながったりすることがある。適用したあとに確かめる。

## 保存と共有

- プロジェクト（メイン回路とすべてのモジュール）は、ブラウザに自動で保存される。
- 「書き出し」で、プロジェクトを JSON にして、文字列としてコピーするか、ファイルに保存する。作者名も付けられる。
- 「読み込み」で、書き出したファイルを選ぶか、JSON の文字列を貼り付けると、そのプロジェクトに置き換わる。読み込み元（ファイル / テキスト）はラジオボタンで選ぶ。
- 「新規作成」で、空のプロジェクトにする。

読み込みと新規作成は、元に戻すで戻せる。

## 環境設定

ヘッダーの右端から開く。

- シミュレーションの速さ（tick/秒、1〜100000）
- 方眼の表示
- 配線の角を丸める
- アクセントカラー
- 言語（自動 / 日本語 / English）

# シートの表示

シートの大きさと、表示（スクロールと拡大縮小）の扱い。表示を動かす操作の割り当ては[画面操作](interaction.md)にある。

## シートの大きさと座標

- シートの大きさは回路ごとに持つ（`CircuitDef.sheet`、単位はマス。1 マスは `GRID` = 20）。持たない回路は横 300 マス・縦 200 マス（`project.ts` の `DEFAULT_SHEET`）。大きさは `getCircuitSheet` で引き、px の右下の角は `layout.ts` の `getSheetEnd` で求める。
- 位置の補正や表示の関数（`clampPosition`、`clampMove`、`placeOffset`、`dragWireEnd`、`centerView`、`fitView`）は、回路の大きさを引数で受け取る。
- 左上が回路の座標の原点。部品は、本体とピンの先がシートに収まる位置にだけ置ける（`clampPosition`）。座標は負にならない。
- シートより外にある部品や配線の点（大きさを決める前に作った回路、手で書き換えたデータなど）も、そのまま表示・計算する。動かしたときに初めてシートの中へ戻る（`clampMove` が、移動先をシートの範囲に収めるため）。開いている回路にそういうものがあると、ステータスバーに警告を出す（[UI](ui.md)の「ステータスバーのヒント」）。
- 収まっているかは `view.ts` の `fitsInSheet`、収まるいちばん小さい大きさは `minCircuitSheet` で求める。部品はピンの先と上の名前まで（`partBounds`）、配線は点で見る。

## シートの大きさを変える

- シートのツールバーの「シート設定」（`sheet/SheetSettingsDialog.tsx`）で、回路ごとに幅と高さ（マス）を変える。1 辺は 20〜1000 の整数（`project.ts` の `MIN_SHEET_CELLS` / `MAX_SHEET_CELLS`）。
- 左上は固定で、右と下で増やしたり減らしたりする。中身はずらさない。
- 部品と配線が収まらない大きさにはできない（開発者が決めた）。収まる大きさ（a × b マス以上）をエラーで知らせる。座標が負のものがあると、どの大きさにしても収まらない。
- 保存データと共有用 JSON には、300×200 の回路も必ず書く（`withCircuitSheet`。読み込み・保存・書き出しで通す）。形は[version 3](../../docs/format/v3.md)の「シートの大きさ」。
- 表示はシートの外まで自由に動かせる。シートの外は色（`sheet.outside`）を変え、境目に線を引いている。シートの大きさを変えるときは、この表示（`Sheet.tsx` の `sheetStart` / `sheetEnd` を使う部分）も確かめる。

## 表示

- 表示（`geometry/view.ts` の `View`）は、表示位置と倍率の組。画面の座標 = 回路の座標 × `scale` + (`x`, `y`)。倍率は 0.2〜3（`MIN_SCALE` / `MAX_SCALE`）。
- 表示は、回路を描く `<g>` の `transform` と、方眼の `patternTransform` の両方に掛ける。ポインターの位置は `toWorld` で回路の座標に直してから使う。HTML の要素は拡大縮小せず、位置だけ `toScreen` で合わせる。
- 拡大縮小は、ポインター（ボタンなら表示の真ん中）の下にある回路の点が動かないように行う（`zoomAt`）。
- 表示は回路ごとに覚え、localStorage に保存する（[保存データ](persistence.md)）。元に戻す対象にはしない。

## 開いたときの表示

- 表示を保存していない回路は、`view.ts` の `overview` で決める。
  - 部品のない回路は、シートの真ん中を画面の真ん中に置いた等倍の表示（`centerView`）。
  - 部品のある回路は、回路全体が見える表示（`fitView`）。等倍より大きくはしない。シートの外が映るなら、シートの端を画面の端に合わせる。既存の回路はシートの左上の近くに部品があることが多く、真ん中を表示すると隠れてしまうため。
- ズームの「回路全体を表示」も `overview` を使う。
- 表示を保存していない回路は、開いた時点の表示をすぐに保存して固定する（`App.tsx`）。固定しないと、部品を置くたびに表示が計算し直され、画面が勝手に動く。

# アイコンとロゴ

画面に出すアイコンとロゴの作り方。色の決まりは[見た目](styling.md)にある。

## アイコン

- アイコンは SVG のファイルとして置く。コンポーネントの中にインラインで書かない。
  - 部品の種類のアイコンは、種類のフォルダ（`src/parts/<種類>/icon.svg`、[部品の種類](parts.md)）。
  - ほかのボタンなどのアイコンは `src/assets/icons/`。
- アイコンの SVG は、CSS の `mask` として使い、形を切り抜いて文字色（`currentColor`）で塗る（`ui/Icons.tsx` の `MaskIcon`）。
  - そのため、SVG の中で指定した色は表示に出ない。塗る部分は不透明な色（`#000`）で描き、透明な部分が背景になる。
  - 色分けしたアイコンが要るときは、この方式を見直す必要がある。
- 大きさ: ボタンのアイコンは 16×16（`ToolIcon`）、部品の種類のアイコンは 32×24（`PartIcon`）。

## ロゴ

- ロゴもアイコンと同じ方式で、ロゴの色（テーマの `brand`）で塗る。ロゴの色は固定で、環境設定のアクセントカラーでは変わらない。
- ヘッダーは花だけ（`src/assets/logo-mark.svg`）、「このアプリについて」は文字付き（`src/assets/logo.svg`）。
- ロゴの「sazanka」の文字は、環境によって字形が変わらないよう、Inter SemiBold（SIL OFL）の字形をパスにして埋め込んでいる。
  - 文字やフォントを変えるときは、opentype.js などでパスを作り直す（大きさ 17px、ベースライン y=20、x=30 から、字間 0.5px）。
  - 文字の幅が変わったら、SVG の `viewBox` と、「このアプリについて」のロゴの大きさ（`app/AboutDialog.tsx` の `MaskIcon` の `w` と `h`）も合わせる。

## ブラウザのタブのアイコン

- `public/favicon.svg` は、ロゴの花だけを抜き出したもの。マスクではなく、ロゴの色（`lightseagreen`）を直接書いている。

## 合わせて直すもの

- 花の形を変えたら、`logo-mark.svg`、`logo.svg`、`favicon.svg` の 3 つをそろえる。
- ロゴの色を変えたら、`theme.ts` の `brand`、`favicon.svg`、既定のアクセントカラー（[見た目](styling.md)の「色」）も合わせる。

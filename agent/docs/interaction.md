# 画面操作

シートとタブで、どう操作すると何が起きるかと、そう決めた理由。編集したデータと元に戻すの扱いは[編集と元に戻す](editing.md)、表示の範囲と倍率は[シートの表示](view.md)、ボタンの置き場所は [UI](ui.md) にある。

操作を足すときは、ここの割り当てとぶつからないかを確かめる。ぶつかるなら、どちらを優先するかを決め、ステータスバーのヒント（`hints/hints.ts` と、文言の表 `i18n/ja.ts` の `hints`）にも書く。

## 選択

選択モードのときの操作。配線モードでは、クリックはすべて配線の点を置く操作になる（下の「配線」）。

- 部品と配線はクリックで選ぶ。ピンを押したときは、その部品を選ぶ（ピンから配線は始めない）。部品と配線は一緒に選べる（`edit.ts` の `Selection`）。
- Shift+クリックは選択に足す・外す（押したものは動かさない）。
- 何もないところからのドラッグは範囲選択。本体の全体が範囲に収まった部品（ピンの先は含めない。`layout.ts` の `partsInRect`）と、すべての点が範囲に収まった配線（`wiresInRect`）を選ぶ。Shift を押しながら始めると、元の選択に足す。
- 選択中の部品か配線を押してドラッグすると、選んでいる部品と配線をまとめて動かす。
- Ctrl+A で、開いている回路の部品と配線をすべて選ぶ。
- Esc を押すと、貼り付け中・配線中・選択をまとめて取り消す。配線モードで配線の途中でなければ、選択モードにも戻る（下の「配線」）。分割モードでも、選択モードに戻る。
- 配線を 1 本だけ（部品も選ばずに）選ぶと、両端に印を出す。印のドラッグで端の区間の長さを変える（下の「配線の調整」）。

## 配線

- 選択モードと配線モードを分ける。`V` で選択モード、`W` で配線モードにする（トグルにしない）。配線を 1 本描き終えても、配線モードのままにする。配線の途中でなければ、Esc でも選択モードに戻る。(開発者からの指示)
  - 分けたのは、何もないところから配線を始められるようにするため。選択モードでは、何もないところのクリックを選択の解除に、ドラッグを範囲選択に使っている。
  - 描き終えても配線モードのままなのは、続けて引けるようにするため。
  - モードは `simulation/SheetToolbar.tsx` の `Tool`。シートのツールバーのボタンでも切り替えられ、今のモードのボタンは地の色を付けて示す（`ToolButton` の `active`）。
  - 配線の途中の Esc で選択モードに戻らないのは、描き直したいだけのときに `W` を押し直さずに済むようにするため。
  - トグルにしないのは、押せば今のモードによらず必ずそのモードになるようにするため。キーは、選択ツールでよく使われる `V` にそろえた。
  - モードが変わるときは、配線中の線を取り消す。配線中に `W` を押しても、何も変わらない。
- 配線モードでは、何もないところ・ピン・配線・部品の上のどこをクリックしても、配線の点を置く（`Sheet.tsx` の `onWireClick`）。点はグリッドに合わせ、シートの範囲に収める。
  - 1 点目: そこから配線を始める。ほかの配線の途中から始めると、そこから分岐する。
  - 2 点目から: 最後の点から縦か横の 1 方向にだけ伸ばす。向きは、ポインターが動いた量の大きい方（`layout.ts` の `wireStepTo`）。クリックした所に折れる点を置き、そこから別の向きへ伸ばせる。
  - 伸ばした先がピンの先か、ほかの配線の上なら、そこでつないで描き終える。
  - 最後の点をもう一度クリックすると、何もないところで描き終える。1 点目をもう一度クリックしたときは、配線にならないので取り消す。
  - Esc で、描いている配線を取り消す。配線モードのままにする。
  - 描き終えるときに、同じ点が続くところと、まっすぐ進む途中の点を省く（`layout.ts` の `simplifyWire`）。
- 配線中の仮の線と、配線モードでポインターの位置に出す丸は、クリックしたときに置かれる点（`wireCursor`）で描く。`onWireClick` と同じ計算にしないと、クリックした後に線が違う位置へ動いて見える。
- 自動で経路を探す方式は、配線が多いと計算が重く、経路が勝手に変わるので採らない。
- 部品を動かしても、配線はついてこない。つながりが切れたら、配線も動かすか引き直す。

## 配線の調整

配線を引き直さずに、長さを変えたり 2 本に分けたりする操作。データの扱い（結合の条件など）は[編集と元に戻す](editing.md)の「配線」にある。

### 端のドラッグ

- 選択モードで配線を 1 本だけ選ぶと、両端に印（アクセントカラーで塗った 6px 四方の四角）を出す。範囲選択で多くの配線を選んだときに、印で埋まらないよう、1 本のときだけにしている。配線モードと分割モードでは出さない。
- 印をドラッグすると、端が端の区間の向きにだけ動く。位置はグリッドに合わせる。縮めるのは隣の折れる点まで、区間が 1 つの配線は 1 マスまで。伸ばす先はシートの範囲で止める。
- 折れる点まで縮めても、離すまでは区間を消さない。戻せばまた伸びる。行き過ぎても、離す前なら直せるようにするため。
- 印に乗ったときとドラッグ中は、印を大きくして縁を付け、ポインターを区間の向きの矢印（`ew-resize` / `ns-resize`）にする。どちらに動くかが、押す前に分かるようにするため。ドラッグ中は、シート全体に同じ形を付けて、印から外れても形を保つ。
- 印の大きさと押せる範囲（20px 四方）は、拡大縮小しても画面上で変えない（`Sheet.tsx` の `HANDLE_SIZE` / `HANDLE_HIT`）。押せる範囲を見た目より広くするのは、スマホの指でも押せるようにするため。
- 印を押しても、少し動かすまで（`DRAG_THRESHOLD`）は何もしない。Shift を押しながらでも、端のドラッグとして扱う。
- 削除エリアで離しても消さない。端のドラッグ中は、削除エリアを反応させない。端だけを動かす操作で、配線ごと消えると驚くため。
- 端がほかの配線の端に重なれば結合し、ほかの配線の途中やピンの先に来ればつながる。重ならないようにするのは、配線を描くときと同じく利用者に任せる。

### 分割モード

- `S` かツールバーの「分割」で分割モードにする。選択モード・配線モードと同じく、トグルにしない。Esc で選択モードに戻る。
- 配線の途中か折れる点をクリックすると、その点（ポインターの位置をグリッドに合わせた点）で 2 本に分ける。1 回のクリックが元に戻す 1 回。分けたあとも分割モードのまま。
- 交差している点とピンの先では分けない。その上ではポインターを `not-allowed` にする。配線の端と、何もないところを押しても何もしない。
- 部品や配線の上を押しても、選択やドラッグは始めない（配線モードと同じく、`onPointerDownCapture` で受けて止める）。
- ポインターの下の分ける点に、アクセントカラーで線と直角の短い線（長さ 12px）を出す。分けた 2 本は 1 本に見えるので、分割モードの間だけ、分かれ目（2 本の端だけが合わさっている点）に、配線と同じ色の短い線（長さ 10px）を出す。どちらも拡大縮小しても画面上の長さを変えない。

## 部品を置く・動かす・消す

- パレットの部品は、クリックでもドラッグ＆ドロップでも置ける。
  - クリックしたときは、表示している範囲の真ん中あたりに置く。続けて置いても重ならないよう、少しずつずらす（`App.tsx` の `addPart`）。
  - INPUT / OUTPUT を置くと、入力と出力で別々に、空いているいちばん小さいポート番号を付ける（`module.ts` の `assignPortNumbers`）。消した番号は詰めない。
  - パッケージが `dip` / `qfp` のモジュールの中に INPUT / OUTPUT を置くと、空いているいちばん小さいピン番号を付ける（`module.ts` の `assignPinNumbers`）。空きがなければ付けない。番号を付けるのは置く操作の一部で、元に戻す 1 回でまとめて戻る。
  - ドラッグ＆ドロップは、落とした位置に置く。ブラウザのドラッグ＆ドロップ（`dataTransfer`、形は `palette/drag.ts`）を使っている。
- 部品の位置はグリッド（20）に合わせ、シートからはみ出さない位置に収める（[シートの表示](view.md)）。
- まとめて動かすときの移動量は、どの部品もはみ出さない範囲に縮める（`layout.ts` の `clampMove`）。全体の形を崩さないため、部品ごとには止めない。
- INPUT は、動かさずにクリックすると ON/OFF が切り替わる。ドラッグしたときは切り替えない。
- モジュールの部品をダブルクリックすると、その中身のタブを開く。
- 部品の項目（CLOCK の周期、ラベル）は、シートではなくプロパティ欄で編集する。使える値になったら、すぐに反映する。
- Delete か Backspace で、選んでいる部品と配線を消す。シートの右下の削除エリアへドラッグしても消せる。部品を消しても、つながっていた配線は残る。

## コピーと貼り付け

- Ctrl+C でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付け。対象は、選んでいる部品と配線。配線だけでもよい。
- 貼り付けた INPUT / OUTPUT のポート番号は、空いている番号ならそのまま残し、重なれば空いている番号にする（`assignPortNumbers`）。
- 貼り付けた INPUT / OUTPUT のピン番号は、貼り付け先に合わせて付け直す（`assignPinNumbers`）。`dip` / `qfp` のモジュールでは、空いている番号ならそのまま残し、ほかと重なるか範囲外なら空いている番号にする。メイン回路と `split` のモジュールでは番号を外す。
- 貼り付けは、押した瞬間には置かない。部品がポインターについてきて、クリックした位置で確定する。どこに増えたのかが分かるようにするため。(開発者からの指示)
  - ポインターがまだシートに来ていない（スマホなど）ときは、表示している範囲の真ん中に出す。
  - 押したまま大きく動かしてから離したときは、確定しない（指で画面をなぞっただけのときなど）。貼り付け中のまま残る。
- 貼り付け先の回路を含むモジュールは貼り付けられない（循環するため）。理由をダイアログで知らせる。
- クリップボードはアプリの中だけで持つ（OS のクリップボードは使わない）。回路の受け渡しは、書き出しと読み込みで行う（[保存データ](persistence.md)）。

## タブ

- タブをクリックすると、その回路を開く。開くのはクリック（Chakra の `Tabs` の選択）だけ。
- タブの末尾の「+」でモジュールを追加する。名前を入れるダイアログで確定して初めて、モジュールができてそのタブが開く。
- モジュールのタブは、ダブルクリックで名前を変えられる（Enter を押すか欄を離れると確定し、Esc で取り消す）。ドラッグで並べ替えもできる。メイン回路のタブは、どちらもできない。
- 押した位置から少し動かしたら（`DRAG_THRESHOLD`）ドラッグとして扱い、タブは開かない。ポインターキャプチャは動き始めてから設定する。押した時点で設定すると、ダブルクリックが効かなくなるため。
- モジュールのタブを並べ替えても、開いているタブは変えない。(開発者からの指示)

## 表示を動かす

- ホイールで拡大縮小する（トラックパッドのピンチも、Ctrl 付きのホイールとして届く）。
- 中ボタンでのドラッグか、Space を押しながらのドラッグで、表示を動かす。
- スマホでは、2 本指で移動と拡大縮小ができる。
- 何もないところからのドラッグは、パソコンでもスマホでも範囲選択になる（表示の移動にはしない）。

## キーボード

- キーボードの操作は `editing/useShortcuts.ts` にまとめている。Ctrl の代わりに Cmd も効く。
- 元に戻すは Ctrl+Z、やり直しは Ctrl+Shift+Z か Ctrl+Y。
- `V` で選択モード、`W` で配線モード、`S` で分割モードにする。Ctrl などの修飾キー付き（Ctrl+W、Ctrl+V など）は、ブラウザの操作やほかのショートカットに任せて受けない。
- 文字を入力している間（input か textarea にフォーカスがある間）と、ダイアログを開いている間は、ショートカットを効かせない。Space による表示の移動も、文字の入力中は効かせない。

## ポインターの扱い（実装の注意）

- シートの上の操作は、すべて Pointer Events で受ける。タッチ専用の処理は持っていない。
- シートには `touch-action: none` を付けている。付けないと、スマホで指を動かし始めた時点でブラウザがスクロールとして扱い、`pointercancel` が来てドラッグが止まる。
- 部品のドラッグでは、シートの `svg` にポインターキャプチャを設定する。削除エリアなど、シートの外まで動きを追うため。
  - キャプチャ中は click や dblclick がシートに届き、部品には届かない。そのため、キャプチャは押した位置から少し動いてから（`DRAG_THRESHOLD`）設定する。押した時点で設定すると、ダブルクリック（モジュールを開く）が効かなくなる。
  - 何もないところから始める範囲選択は、クリックしても何も起きないので、押した時点でキャプチャする。
- ホイールは `addEventListener` に `passive: false` を付けて登録している。React の `onWheel` は passive になり、`preventDefault` が効かずにページごと拡大されてしまうため。
- 表示を動かす操作は `sheet/useViewGestures.ts` にまとめ、シートのポインターのイベントから呼ぶ。表示の移動と 2 本指の操作は `onPointerDownCapture` で子要素より先に受け、そこで止める。部品の上から始めても、部品のドラッグや配線が始まらないようにするため。
- 2 本目の指が触れたら、1 本目で始めていた部品のドラッグや範囲選択は打ち切る。2 本指の操作のあとは、指がすべて離れるまで 1 本目の操作を再開しない。
- 削除エリアとズームは、自分の上で起きた `pointerdown` をシートへ伝えない。その上から押しても、範囲選択が始まらないようにするため。
- 配線モード・分割モードと貼り付け中のクリックも、`onPointerDownCapture` で受けて止める（表示を動かす操作のあと）。部品や配線の上を押しても、選択やドラッグが始まらないようにするため。

## 触ったら確かめること

タブバー（`TabBar.tsx`）を触ったら、ヘッドレスブラウザ（Skill の `browser-check`）で次を確かめる。Chakra の `Tabs` の選択と、自前のドラッグ・名前の変更が同じ要素に乗っているので、片方を直すともう片方が壊れやすい。

- 「+」でモジュールを追加すると、タブが増えてそれが開く。
- タブをクリックすると、その回路に切り替わる。
- モジュールのタブをダブルクリックすると名前を変えられ、Enter で確定する。
- モジュールのタブをドラッグすると並べ替えられ、ドラッグ中は点線の枠が出る。並べ替えても、開いているタブは変わらない。
- 並べ替えのあと、元に戻すが押せる。

シートの操作（`Sheet.tsx`、`SheetPart.tsx`）を触ったら、次も確かめる。部品のドラッグとダブルクリックが同じ要素に乗っているので、ポインターの扱いを変えると壊れやすい（上の「ポインターの扱い」）。

- モジュールの本体をダブルクリックすると、その中身のタブが開く。何も選んでいない状態からと、そのモジュールを選んでいる状態からの両方で試す。
- 部品をクリックすると選ばれる。押した位置から少し動かすと（`DRAG_THRESHOLD`）ドラッグになり、部品が動く。
- 配線を 1 本選ぶと両端に印が出て、印のドラッグで長さが変わる。配線の途中のドラッグでは、今まで通り配線ごと動く。
- 端のドラッグ中に Ctrl+Z、Esc、`V` / `W` / `S`、2 本目の指が来ても、離すか打ち切ったところで壊れずに終わり、元に戻す 1 回で戻る。

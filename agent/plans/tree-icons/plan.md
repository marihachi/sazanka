## 目的

プロジェクトパネルの木の行に、フォルダか回路かが一目で分かるアイコンを付ける（2026-10-24、開発者が求めた）。

## 決めたこと

開発者が決めたこと（2026-10-24）。

- アイコンは、プロジェクトパネルのツールバーとそろえる。フォルダはフォルダの形でオレンジ（`orange.400`）、回路はチップの形で緑（`green.400`）。形は、ツールバーの「新しいフォルダ…」「新しい回路…」のアイコンから「＋」を除いたもの。
  - メイン回路も回路のアイコンにし、右端の ★ はそのまま残す。
  - 採らなかった案: 色を付けない（文字と同じ色）。メイン回路だけ ★ をアイコンの位置に移す。
- アイコンのファイルは `src/assets/icons/circuit.svg` と `src/assets/icons/folder.svg`（ツールバーの `new-circuit.svg` / `new-folder.svg` と対になる名前）。採らなかった案: `tree-circuit.svg` / `tree-folder.svg`。
- 小さな計画として、計画の文書とブランチと PR を作って進める（開発者が決めた。この答えを始める合図とした）。

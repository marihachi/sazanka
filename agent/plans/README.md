# 計画の一覧

段階に分けて進める大きな作業の計画。書き方と状態の決まりは[ドキュメントの書き方](../docs/documentation.md)の「計画の文書」にある。

完了した計画は記録で、今の仕様とは食い違うことがある。今の仕様は、エージェント向けのドキュメント（[AGENTS.md](../../AGENTS.md) から辿る）と形式の文書（`docs/format/`）にある。

番号は計画を書いた順に振る。新しい計画には、いちばん大きい番号の次を振り、表の先頭に足す（新しい計画ほど上）。番号はあとから振り直さない。(開発者からの指示)

| ---- | ----------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------- |
| 11   | [保存データの version 4](format-v4/plan.md)                 | 計画中 | 部品の位置と配線の点を、px ではなくマス単位で保存する。ほかの形式の変更とまとめて上げる |
| 10   | [シミュレーションの速さの見直し](tick-rate/plan.md)          | 完了   | tick の速さを 1 秒あたりの tick 数で指定し、計算を速くして 100 kHz まで動かせるようにする |

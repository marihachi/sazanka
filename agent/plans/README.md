# 計画の一覧

文書にした計画。書き方と状態の決まりは[ドキュメントの書き方](../docs/documentation.md)の「計画の文書」にある。この一覧と計画の文書の冒頭の状態は `main` でだけ直す（作業用のブランチの上では直さない。マージのときにぶつからないようにするため）。

完了した計画は記録で、今の仕様とは食い違うことがある。今の仕様は、エージェント向けのドキュメント（[AGENTS.md](../../AGENTS.md) から辿る）と形式の文書（`docs/format/`）にある。

番号は計画を書いた順に振る。新しい計画には、いちばん大きい番号の次を振り、表の先頭に足す（新しい計画ほど上）。番号はあとから振り直さない。(開発者からの指示)

「前提」は、先に終える計画の番号。その計画が終わってから始める。上位の計画（下位の計画に分けたもの）では、下位の計画の番号を書き、それがすべて終わってから完了にする。

「内容」は 35 文字以内で書く（全角も半角も 1 文字と数える）。詳しくは計画の文書に書く。(開発者からの指示)
